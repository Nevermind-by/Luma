# История изменений

Здесь фиксируются изменения, заметные пользователю или важные для сопровождения проекта.

До первого публичного релиза история изменений ведётся по состоянию разработки. После появления версий список будет разделён по номерам релизов.

## В разработке

### Добавлено

- поиск установленных приложений в стандартных каталогах macOS;
- определение bundle identifier, имени, версии и источника установки;
- модель источников обновлений через `UpdateSource`;
- интеграция с AppsTorrent;
- авторизация через `WKWebView` с сохранением сессии;
- поиск и проверка обновлений;
- загрузка обновлений с поддержкой отмены и сохранения состояния;
- передача внешних установщиков macOS;
- контроль завершения установки;
- прямой сценарий замены `.app` с резервной копией и откатом при ошибке;
- GitHub Actions для сборки, тестов и проверки релизных артефактов;
- единый каталог локализации для английского, русского, немецкого, французского, испанского, упрощённого китайского и японского;
- UI-тесты запуска приложения в каждой поддерживаемой локали.

### Изменено

- язык приложения теперь выбирается стандартным механизмом локализации macOS по предпочтениям пользователя;
- документация уточняет источник выбора языка и поведение резервной локализации;
- усилена проверка cookies для загрузок и перенаправлений;
- усилена проверка содержимого ZIP и DMG;
- кнопки установки адаптированы под длинные переводы с переносом и переключением раскладки;
- пользовательский текст в коде подготовлен для String Catalog;
- документация приведена в соответствие с текущей реализацией;
- автоматическая публикация GitHub Release отключена до готовности первого публичного релиза;
- финальная проверка прямой замены `.app` дополнительно подтверждает bundle identifier, версию и криптографическую подпись уже установленного приложения.

### Планируется

- дополнительные источники обновлений;
- более надёжное сопоставление приложений с источниками;
- фоновые проверки;
- уведомления;
- дополнительные настройки приложения;
- дополнительные языки и проверка локалей;
- подписанный и нотариально заверенный публичный релиз.
